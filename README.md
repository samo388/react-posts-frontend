# React Posts Frontend

Frontend application built with **React + Vite** that consumes a Laravel REST API.

## 🚀 Features

- User authentication (Login / Register)
- Create, read, update, and delete posts
- Auth context with token-based authentication
- Protected routes
- Axios API layer

## 🛠 Tech Stack

- React 18
- Vite
- React Router DOM
- Axios
- Context API

## 🔗 Backend API

Laravel REST API:
👉 https://github.com/samo388/laravel-posts-app

## ⚙️ Setup & Run

```bash
npm install
npm run dev
```
